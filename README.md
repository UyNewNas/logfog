# LogFog · 工时描述混淆器

在填写工时时，点浏览器工具栏里的 LogFog，把一段工作记录换成另一种口吻。也可以直接选中网页上的原文，通过右键菜单送入扩展。所有改写都在本地运行，安装后可以断网使用。

## 安装 Chrome 或 Edge 扩展

1. 下载 [LogFog 扩展 ZIP](https://github.com/UyNewNas/logfog/raw/refs/heads/master/dist/logfog-extension.zip)，解压到打算保留的位置。
2. 在 Chrome 地址栏打开 `chrome://extensions/`，在 Edge 打开 `edge://extensions/`。
3. 打开「开发者模式」，点击「加载已解压的扩展程序」，选择**直接包含 `manifest.json` 的文件夹**。
4. 从浏览器的扩展菜单把 LogFog 固定到工具栏。

如果已经克隆本仓库，可以在第 3 步直接选 [extension](extension/) 目录。当前分发方式为本地加载，适用于基于 Chromium 102 或更新版本的桌面浏览器。

## 使用

- **粘贴改写**。点击工具栏图标，输入或粘贴工作记录，选择「清爽直述」「专业汇报」或「大厂黑话」，再点击「生成描述」。
- **选中改写**。在工时系统或其他网页上选中一段文字，右键选择「用 LogFog 改写选中文字」。扩展会带入选区并生成第一种写法。若浏览器不支持从右键菜单直接弹出工具栏面板，LogFog 会用独立小窗显示结果。
- **挑选与复制**。每种风格有三种写法。点击「换个说法」循环比较，点击「复制结果」后粘贴回工时系统。在输入框按 `Ctrl+Enter` 或 macOS 的 `⌘+Enter` 也能生成和切换。
- **继续上次的记录**。收起再打开面板，可以继续编辑当前草稿。「清空」移除本次文本。草稿使用浏览器会话内存，浏览器重启后清除。

扩展只申请右键菜单与会话存储权限。打开网页时不会读取正文，只有主动使用右键菜单时才接收选中的文字。无需 API Key，输入不会发送至服务器。复杂条件句及陌生术语会较多保留原文。

## 单文件网页与开发

原来的 [离线网页](index.html) 仍可下载后双击使用。扩展目录已包含可直接加载的全部文件，无需构建。改写规则以 `extension/rewrite.js` 为准。修改扩展后运行 `python3 scripts/package-extension.py`，即可重建下载包，并把同一份规则嵌入单文件网页。

在仓库根目录使用 Node.js 18 或更新版本运行：

```sh
node --test tests/rewrite.test.cjs tests/extension.test.cjs
```
