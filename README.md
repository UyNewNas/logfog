# LogFog · 工时描述混淆器

把同一段工时记录改写成不同口吻。页面内置中文改写规则，所有运算都在浏览器里完成。

## 离线使用

1. 下载本仓库的 ZIP 并解压，或单独下载根目录的 [index.html](index.html)。
2. 双击 `index.html`，用 Chrome、Edge、Firefox 或 Safari 等现代浏览器打开。断网即可使用，无须安装软件、启动服务器或配置 API Key。
3. 输入一段工作记录，选择「清爽直述」「专业汇报」或「大厂黑话」。点击「生成描述」，再点「换个说法」比较同一风格的不同写法。「复制结果」可将选中的写法带入工时系统。

可在输入框中按 `Ctrl+Enter` 生成或切换写法，macOS 使用 `⌘+Enter`。历史面板能找回当前页面最近 30 条生成记录，刷新或关闭页面即清除。

## 改写方式

例如输入「看了下登录接口的报错日志，修了超时问题，补了 2 条回归用例。」三种风格分别侧重简短动作、正式汇报和抽象的职场表达。每种风格提供三种写法，点「换个说法」循环比较。

词库涵盖研发测试、项目沟通、文档、会议和日常办公。遇到陌生表达或带有条件、否定的复杂句时，工具会更多保留原句，通过记录格式来区分口吻。工时、数量与项目术语来自输入。可以用反引号包住希望原样显示的命令或标识符。

## 开发与验证

单文件包含页面样式、改写规则和交互代码。修改 `index.html` 后，刷新浏览器即可试用。使用 Node.js 18 或更新版本可在仓库根目录运行回归检查：

```sh
node --test tests/rewrite.test.cjs
```
